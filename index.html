Challenges & how I solved them

A few real problems from building the recipe app.

AI integration

Keeping Gemini's cooking answers relevant and safe to serve

Problem: A general-purpose AI model can wander off-topic or give inconsistent answers to cooking questions.

Solution: Scoped the prompts sent to Google Gemini so the assistant only responds to cooking-related questions, and structured requests around the recipe context so answers stay consistent with what the user is viewing.

Feature design

Turning live weather into a food recommendation

Problem: Weather on its own doesn't tell you what someone wants to eat — it needed to combine with a personal preference.

Solution: Paired live weather data with a simple healthy/comfort food toggle the user sets, so the recommendation engine narrows results using both signals instead of guessing from weather alone.

Access control

Gating premium challenges without duplicating logic

Problem: Premium-only features (recipe challenges) needed the same access rules enforced in the Flutter app, the API, and the Next.js admin panel.

Solution: Centralized the user-tier check in the backend behind protected routes, so the mobile app and admin panel both defer to one source of truth instead of duplicating permission logic client-side.

Cloud storage

Moving image handling to Supabase

Problem: Recipe photos needed reliable, fast storage that both the mobile app and admin dashboard could read from.

Solution: Used Supabase Storage as the single image source for uploads from the Flutter app, keeping URLs in MongoDB so the admin panel and API stay in sync without re-uploading files.
